## Shortcuts

+ `Alt + Shift + Z` : try-catch blokken en nog veel meer
+ `Cntrl + L (line number)` : ga naar de opgegeven lijn
+ `Cntrl + 1`: toon de suggesties om een error te fiksen
+ `Shift+Alt+S`: toon source
+ `cntrl + space`: e.g. type `for`, and a bunch of suggestions pops up. Idem voor if-statements
